# Đóng góp vào repository

Hướng dẫn đóng góp tiếng Việt đầy đủ, gồm branch/commit, kiểm tra, review, API chung, Issue và
quy tắc dữ liệu/bí mật, nằm trong [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).

Trước khi sửa code hãy xem [docs/TEAM_ASSIGNMENTS.md](docs/TEAM_ASSIGNMENTS.md) để xác định owner,
[docs/WORKFLOW.md](docs/WORKFLOW.md) để phối hợp qua PR, và
[docs/DEVELOPMENT_GUIDE.md](docs/DEVELOPMENT_GUIDE.md) để giữ giao diện/schema ổn định.
