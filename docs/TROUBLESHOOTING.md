# Khắc phục sự cố

Các mục dưới đây là hướng dẫn chung theo mã hiện tại; không có nghĩa mọi lỗi đều đã xảy ra trên
máy của bạn. Chạy lệnh từ repository root và dùng Python trong `.venv` đang hoạt động.

| Triệu chứng | Nguyên nhân có thể | Chẩn đoán | Cách xử lý an toàn | Xác minh |
|---|---|---|---|---|
| `Python version` thấp hơn 3.11 / cài package bị từ chối | Đang gọi nhầm interpreter | PowerShell: `python --version`; Unix: `python3 --version` | Cài/chọn Python 3.11+; tạo lại `.venv` bằng đúng executable, không xóa dữ liệu dự án | Chạy lại version rồi `python -m pip --version` |
| `python`/package trỏ ra ngoài `.venv` | Virtual environment chưa activate hoặc terminal cũ | PowerShell: `Get-Command python`; Unix: `which python` | Activate environment hoặc chạy `.venv\Scripts\python.exe` (Windows), `.venv/bin/python` (Unix) | `python -c "import sys; print(sys.executable)"` phải trỏ trong `.venv` |
| `ModuleNotFoundError: qkd_pqc`, `yaml` hoặc `matplotlib` | Chưa cài editable project/dependencies trong interpreter đang dùng | `python -m pip show qkd-vs-pqc PyYAML matplotlib` | Từ root: `python -m pip install -e ".[dev]"`; không dùng pip global | `python -c "import qkd_pqc, yaml, matplotlib"` |
| Cài dependency lỗi mạng/build | Package index không tới được, Python/OS wheel không tương thích | Đọc lỗi đầy đủ của `python -m pip install -e ".[dev]"`; xem `python --version` | Xác nhận mạng/index/phiên bản; retry theo chính sách IT, không thay dependency tùy tiện | `python -m pip check`, sau đó chạy test |
| Script báo không tìm thấy config | Đường dẫn config không tồn tại hoặc chạy lệnh sai project | PowerShell: `Get-Location`; `Test-Path configs\experiment_config.yaml`; Unix: `pwd; ls configs/experiment_config.yaml` | `cd` về root hoặc truyền `--config` với file YAML có thật; đường dẫn tương đối được tính từ root dự án | `python scripts/run_qkd.py --config configs/experiment_config.yaml` |
| Lỗi config về xác suất, số vòng lặp hoặc thuật toán | Giá trị không hợp lệ/thiếu; chỉ nhận đúng `ML-KEM-768` | Mở YAML; chạy `python -m pytest tests/test_config.py` | Chỉnh YAML: probability [0,1], signal/repetitions dương, warm-up không âm, seed không âm | Chạy lại script/test config |
| `FileNotFoundError`/CSV header thiếu trong analysis | Chưa chạy experiment, file bị đổi tay, hoặc schema từ phiên bản khác | Liệt kê `data/raw`; mở dòng header CSV; đọc thông báo cột thiếu | Chạy thí nghiệm thật; không thêm số giả; giữ header đúng DATA_DICTIONARY hoặc chuyển đổi dữ liệu bằng bước rõ ràng | `python scripts/run_analysis.py` |
| CSV đã tồn tại và không ghi được | Writer raw dùng exclusive mode để tránh ghi đè | Kiểm tra tên file `data/raw` và traceback `FileExistsError` | Không xóa raw; chạy lại để sinh run ID khác. Nếu tự tạo file va chạm, chọn tên riêng | File cũ không đổi và run mới được ghi thành công |
| Permission error khi ghi output | Quyền thư mục hoặc path cấu hình không phù hợp | Kiểm tra output path trong YAML và quyền ghi | Chọn thư mục tương đối có quyền ghi; không trỏ output vào thư mục hệ thống | Chạy QKD với config sửa đổi |
| Không thấy hình hoặc có warning “No valid measurements” | CSV rỗng/giá trị không số/ngoài [0,1] hoặc thiếu mẫu | Xem warnings terminal và các cột được yêu cầu | Thu thập input hợp lệ; phân tích bỏ qua hàng lỗi thay vì nội suy hoặc tạo dữ liệu | Chạy tests `tests/test_plotting.py`; chạy analysis lại |
| Plot ghi đè PNG cũ | Tên hình hiện cố định theo loại biểu đồ | Kiểm tra thời gian file trong `figures/` | Sao lưu/copy hình cần giữ ra ngoài trước khi chạy lại; CSV nguồn vẫn riêng biệt | So sánh ảnh với CSV input tương ứng |
| ML-KEM báo implementation unavailable | Optional `pqcrypto` thiếu, không có module/API đúng hoặc self-test thất bại | Chạy capability command trong USER_GUIDE; chạy `python -m pip show pqcrypto`; `openssl list -kem-algorithms` chỉ tham khảo | Cài optional extra `python -m pip install -e ".[mlkem,dev]"` nếu phù hợp; không thay thuật toán | Capability phải trả adapter đã xác minh; benchmark vẫn cần chạy riêng |
| OpenSSL không liệt kê ML-KEM | OpenSSL/backend CLI hiện tại không quảng bá thuật toán | `openssl version`; `openssl list -kem-algorithms` | CLI benchmark không dùng OpenSSL; không suy ra khả năng từ version, cài bản khác nếu policy cho phép rồi kiểm tra lại | Dùng capability check của adapter, không chỉ OpenSSL |
| ML-KEM correctness test skip | Adapter chưa phát hiện backend tương thích | Summary pytest hiển thị `SKIPPED`; capability command trả `None` | Nếu cần benchmark thật, cài backend tương thích; nếu không, ghi rõ skipped | Chạy lại test; xác nhận test chuyển sang chạy, không chỉ coi skip là pass |
| Import/test fail sau khi đổi signature | Consumer hoặc test chưa được cập nhật theo API mới | `python -m pytest`; tìm traceback/call site | Trao đổi với owner, cập nhật caller/tests/docs trong PR tương thích; không thêm fallback im lặng | Chạy toàn bộ tests sau thay đổi API |
| Xung đột Git | Hai nhánh sửa cùng file/shared interface | `git status`; xem conflict markers và lịch sử PR | Không xóa thay đổi người khác; trao đổi với owner, resolve có chủ đích rồi test | `git diff --check`, tests liên quan, commit merge resolution |
| `git push` báo không có remote/quyền | Repository chưa clone đúng remote hoặc chưa được cấp quyền | `git remote -v`; `git status --short --branch` | Xác nhận URL/permission với quản trị viên; không tự thêm remote không rõ nguồn | Push branch sau khi remote được xác nhận |

Không lưu secrets, private keys, nội dung shared secret hay `.env` vào issue/terminal transcript
công khai.
